CBC IESTP DRELM v2.3 - ADMINISTRACIÓN

1. Ejecutar ACTUALIZACION_V23_ADMIN.sql UNA SOLA VEZ en Supabase > SQL Editor.
2. El script fija lisidro@drelm.gob.pe como Administrador.
3. Reemplazar los archivos del repositorio por esta versión y publicar en GitHub.
4. Ingresar con lisidro@drelm.gob.pe: aparecerá el menú Administración.
5. Especialistas no verán este módulo.

IMPORTANTE: El panel habilita/retira usuarios que ya existen en Supabase Authentication. Para crear una cuenta nueva, créala primero en Authentication > Users.

Las fichas finalizadas quedan bloqueadas para especialistas. El administrador puede ANULAR una ficha conservando trazabilidad o ELIMINAR una ficha de prueba con doble confirmación. La limpieza total conserva usuarios y padrón.
